# 个人工作约定

- Windows、PowerShell、中文路径。用绝对路径与 LiteralPath，调用 npm CLI 的 `.cmd` 或实际 `.exe`，不依赖被执行策略阻止的 `.ps1`。优先 rg，不可用就换本机工具。
- 行为树、关卡/剧情/地图等配置任务分别按已安装的对应专业技能处理；先读实际配置，不猜结构。
- 表格文件修改读取对应表格安全技能；原始字节备份、原生编辑器打开、结构与业务校验是完成条件。同一工作簿串行写，活动工作簿留给有原生工具的主控，执行代理可以先做只读分析。不能用“自动化”跳过候选文件验证。
- 文本类库文件修改保持原编码、BOM、换行与其他字段。
- 版本控制先确认当前路径映射和未提交基线，逐个明确文件操作，保留无关文件。只对当前工作区使用对应分支工作流；不把某分支配置强加给其他目录。提交与提审按用户已授权范围完成，准备文件与验证不用反复问。
- 协作/消息类任务先读取对应技能，live 数据先 whoami/doctor。需要工具未传给执行代理时由主控处理；不把鉴权文件或 token 写进任务简报、plan、日志。消息发送与高风险写入遵循用户原有授权规则。
- 不修改用户全局模型、权限、MCP 设置。专业工具只在有该能力的环境中使用；缺少原生工具或连接时保留候选或分析结果交主控，不假报验证成功。
